# The AGI Manual

A structured reference for understanding AGI - the concepts, architectures, and open problems being worked on today.

**Live:** [the-agi-manual.vercel.app](https://the-agi-manual.vercel.app)

---

## What's inside

- Core AGI concepts and terminology
- Hyperon and MeTTa — iCog Labs' framework for building AGI systems
- Knowledge representation, reasoning, and learning architectures
- Summaries of key papers and whitepapers from the field

---

## Built with

Next.js, MDX, Tailwind CSS - content-first, fast, readable.
